# Nuzlocke-Rule-Maker
A single-page tool to browse, share and create Pokémon Nuzlocke Challange rulesets. No install, no dependencies: just open `index.html`.

## Features

- **Presets:** Classic, Hardcore, Soul Link and the I&C preset, a ruleset I created to play with my girlfriend. Feel free to try it, couples and singles alike!
- **Custom mode:** switch rules on or off, edit their text, add your own rules, or start from any preset.
- **Save and load:** download your custom rules as a `.json` file and load them back whenever you want.
- **Copy as text:** export the active rules as plain text to send to a friend.

## Usage

Open the page, pick a preset, and click a rule to read it. Use the arrows to switch box.
To make your own ruleset, press "Customize this preset" or open the Custom tab.

## Notes

The Classic, Hardcore and Soul Link presets are based on commonly used Nuzlocke rules (see the [Bulbapedia Nuzlocke article](https://bulbapedia.bulbagarden.net/wiki/Nuzlocke)). Nuzlocke rules vary from player to player, so treat every preset as a starting point.
